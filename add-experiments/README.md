# Add experiments here

Drag new photos or videos into this folder and click **Commit changes**.
A few minutes later they appear on the Experiments page, and the files you uploaded are cleared from this folder.

**Name each file like this:**

```
2025 - Sand Wave - Houdini.mp4
```

Year, title and medium, separated by ` - ` (space, hyphen, space).

- **Keep a video's sound:** add ` - sound` to the end, e.g. `2023 - VOLVER - Motion - sound.mp4`. Without it, the audio is removed.
- **Two mediums:** join them with `_`, e.g. `2025 - Arbol de Manzanilla - Motion_Illustration.mp4`, which displays as "Motion / Illustration". Avoid `/` in filenames: a Mac saves it as `:`, which some systems reject.
- **Formats:** MP4 or MOV videos, JPG, PNG or WebP images. Full-size exports are fine; everything is resized and compressed for you.
- **Size:** files dragged in through the GitHub website must be under 25 MB. For anything bigger, see "Uploading a big file" in the main README.

To remove or rename a piece later, delete or rename its file in `media/`.
